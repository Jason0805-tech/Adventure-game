# 🌲 Forest Wanderer

**A 2D survival adventure game built with Godot Engine.**

Forest Wanderer is an independent adventure game focused on exploration, survival, resource management, and environmental interaction.

Players explore a forest environment, collect resources, craft equipment, interact with wildlife, and overcome environmental challenges.

The ultimate objective is to survive three nights in the wilderness.

This project is actively under development.

## 🌍 Gameplay Overview

Forest Wanderer combines survival mechanics with an explorable environment.

Players must balance exploration, resource collection, crafting, and survival while responding to the changing conditions of the forest.

### Core Gameplay Loop

Explore → Collect Resources → Craft Equipment → Survive → Progress

The game includes a dynamic day-night cycle, environmental lighting, wildlife interactions, resource collection, and equipment management.

Different environmental conditions introduce different challenges.

### Survival Objective

Survive three consecutive nights.

Players must prepare during the daytime and manage increasing environmental threats after sunset.

The game includes:

- Health and hunger management
- Resource gathering
- Equipment crafting and repair
- Wildlife encounters
- Combat mechanics
- Environmental lighting
- Nighttime survival challenges

---

## ⚔️ Game Features

### Exploration

Explore a forest environment containing natural resources, wildlife, and interactive objects.

### Resource Collection

Gather materials through activities including:

- Wood collection
- Mining
- Fishing
- Environmental interaction

Collected resources can be used for crafting and survival.

### Crafting System

Craft useful tools and equipment using collected materials.

The crafting system includes resource requirements and item management.

### Inventory System

Manage collected resources and equipment through:

- A 24-slot backpack
- A 6-slot quick-access toolbar
- Item selection and equipment management

### Wildlife System

The forest contains animals with different behavior patterns.

Wildlife behavior varies depending on species, environmental conditions, and time of day.

Some animals avoid players, while others may become hostile.

### Day-Night Cycle

The game uses a dynamic lighting system with transitions between daytime, dusk, and nighttime.

Nighttime visibility is limited, making light sources important for survival.

### Lighting System

Players can use torches to improve visibility.

The environment also includes fixed lighting sources such as the camp lantern.

### Combat and Survival

Players must respond to hostile wildlife and manage health, equipment, and available resources.

### Mobile Controls

The web version includes touchscreen controls.

Mobile compatibility is still experimental and may vary between devices and browsers.

## 💻 Installation

### Requirements

- Godot Engine 4.7
- A compatible desktop operating system

### Run from Source

1. Download or clone this repository.

2. Open Godot Engine.

3. Select **Import**.

4. Locate the following directory:

   `output/0.1.6 series/adventure game 0.1.6.4/`

5. Select `project.godot`.

6. Import and open the project.

7. Run the project using F5.

The current main scene is defined in the Godot project configuration.

### Web Version

Web export files are available in the current version directory.

The web distribution includes browser-compatible game files and additional launch instructions.

Some browsers may require the game to be served through a local web server rather than opened directly as a local HTML file.

For additional information, refer to the web instructions included with v0.1.6-alpha.4.

### Mobile Browser Testing

The web version includes touchscreen controls designed for mobile interaction.

Landscape orientation is recommended.

Physical-device compatibility is not guaranteed.
