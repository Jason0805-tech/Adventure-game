# Forest Wanderer — v0.1.6-alpha.4

这是独立的本地开发版，基于 0.1.6.3。英文游戏界面，保留原来的高清油画美术、角色动画和三夜目标。

## 打开游戏

- 直接玩网页版：双击 **启动网页版.command**。保持弹出的窗口打开，浏览器会打开这一版游戏。停止时在该窗口按 Control+C。
- 修改工程：用已安装的 Godot 4.7.2 导入本文件夹里的 **project.godot**，按 F6 或 F5 运行。
- 请保留整个版本文件夹。`web-share/index.html` 需要通过启动器打开，不能把这个小 HTML 文件单独发送给朋友。

这个启动器只允许当前电脑访问，没有公开发布。手机按钮和布局保留在网页版中；在地址末尾加 `?touch=1` 可以在电脑上预览手机布局。此版本未在实体 iPhone 上测试。

## 这一版怎么玩

白天 180 秒，傍晚 6 秒，夜晚 90 秒。活过三晚获胜。刷新或关闭后重新开始，没有存档。

- WASD / 方向键移动；E 采集、交谈、使用工作台；Space / 点击使用当前物品。
- B 背包；C 野外制作；1–6 选择快捷栏；H 用药；T 切换副手火把。手机布局保留 Move、Gather、Use、Bag、Craft、Heal、Torch、Pause。
- 夜间无灯时每秒减少 0.35 理智。火把和营地灯可以保护理智。站在营地灯下、停止移动和行动、附近没有危险动物，3 秒后开始恢复理智。
- 营地灯会拖慢捕食者并让它们犹豫，但不能保证你不受攻击。背包、制作、对话、暂停、失焦或手机竖屏会暂停整个世界。
- 狼能短时间追上你，但会疲劳。利用灯光、障碍和攻击预警脱身。熊出现 CHARGE 预警后向侧面移动。
- 理智低于 70 会出现轻微视觉干扰；低于 30 可能出现一只真正可战斗的暗影。找灯光、恢复到 35 以上或击败它都能消除威胁。
- 饥饿每分钟消耗 8 点。浆果和鱼是食物；鱼也恢复少量理智。铁斧采集更快，升级剑挥动更快，工作台新增魔法石配方。第一次拜访 Ash 可获得一次补给。

## 文件

`main.gd` 是入口；新的理智规则在 `sanity_system.gd`，平衡数值在 `survival_balance.gd`，捕食者战术在 `predator_behavior.gd`。`assets/` 是原始高清素材。`tools/` 内保留官方单线程 Web 导出模板，所以再次导出不依赖旧版本文件夹。

详细修改、数值和验证范围见 **CHANGELOG.md**。所有测试脚本、日志和截图保存在项目根目录的 `tests/0.1.6.4/`。
