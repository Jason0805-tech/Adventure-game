# v0.1.7 信标主线 — 生图提示词

## 玩法设计（这些图要表现的东西）

胜利条件改成：修好森林深处的古老信标，点亮它，逃离森林。不再限制天数，昼夜照常循环。

| 零件 | 在哪里 | 怎么拿到 |
| --- | --- | --- |
| 信标透镜 Beacon Lens | Stillwater 湖 | 湖面偶尔出现发光的水花，在那里用鱼竿钓几次才能钓上来 |
| 青铜齿轮 Bronze Gear | 矿区 | 一块刻着古老花纹的特殊矿岩，要用铁镐挖开 |
| 余烬核心 Ember Core | 西北森林深处 | 长满苔藓的石头祭坛上放着核心；晚上狼群在附近活动 |

集齐 3 个零件，加上原木和矿石，就能在信标旁修好它。修好后，晚上点火启动：要往火里添柴并守住信标 60 秒。启动成功就能逃离森林。

## 怎么生成

1. 用 ChatGPT（或你常用的生图工具）生成下面 **3 张图**，一张一张来。
2. 每次生成都附上这 3 张参考图，让画风和游戏现有美术一致：
   - `其他/tests/art-previews/001/oil-cartoon-scene.png`（整体画风）
   - `output/0.1.6 series/adventure game 0.1.6.5/assets/utility-props.png`（场景道具画法）
   - `output/0.1.6 series/adventure game 0.1.6.5/assets/utility-icons.png`（物品图标画法）
3. 生成结果要求**背景透明的 PNG**。如果工具不支持透明背景，就用纯色背景，由我来抠图。
4. 生成好的图放进这个文件夹，按下面写的文件名保存。拿不准的话直接发给我看。
5. 不满意可以多生成几次，挑一张最像游戏现有画风的就行。
