0.1.6.2 原画腿部动画素材与实现

这版直接使用 0.1.6 原来绘制的五种动物，包括它们原有的毛边、渐变、爪子和鹿蹄。
没有生成新位图，没有用单色几何腿替换原画，没有降低图片分辨率。原画和六份生图提示词在相邻的 ../0.1.6/ 中；五张发布 PNG 的 SHA256 与 0.1.6 完全一致。

实现方式
- 八个朝向各固定使用原图第零帧的身体。静止直接绘制完整原图，原来身体和腿的像素都保持原样。
- 40 个朝向共 124 个实际可见的腿部区域，由原画的 UV 纹理网格运动。被身体或尾巴完全遮住的腿不会凭空补画。
- 步态随实际移动距离按正向完整循环推进：支撑、抬脚、向前回收、落地。没有倒放循环，也没有整条腿绕身体旋转。
- 使用沿原图纵向变化的平移权重，保留原来的笔触和脚型。4 原生像素的网格行内使用仿射权重，并限制向上的位移，防止有色三角形翻面或撕裂。
- 切口下方的少量接缝使用同一条原图毛色边缘作纹理连接，画在身体和腿的后面。独立脚掌下方不连接，避免脚之间出现蹼。
- 身体网格缓存，只有腿部顶点随循环变化。所有源区域切分均已离线编译至 animal-skin-topology.bin，实际游戏不会首次绘制时重新做布尔切分。
- 源区域的 2 原生像素保护边和 31 处运动时脚掌注册偏置均已归档。没有修改世界碰撞、AI、物品、昼夜或光照逻辑。

文件
- animal_gait.gd：最终发布的原画 UV 动画模块。
- animal_atlas.json：最终完整源注册元数据；source_skin 是使用中的新定义。
- source-legs-*.json：五种动物的最终八朝向注册，包含保护边与最后的地面偏置。
- animal-skin-topology.bin：40 组已编译的源切分、UV、身体/腿网格与原画接缝。
- compile_skin_topology.gd 与 native_seams.gd：重新编译所需脚本，常规运行不需要加载这些作者工具。
- source-and-runtime-hashes.json：五张原图与最终模块、元数据、二进制的 SHA256。
- GIF/PNG：最终源代码绑定的软件 Canvas 回放预览；不是声称人工原生 GPU 试玩的截图。

最终验证
- 40 组编译定义、全部 UV 与原图哈希验证：84,678 项检查通过。
- 独立检查 634,398 个有色源像素，零遗漏和重复；827,000 次有色三角相位检查，零翻面、塌缩、孔洞。
- 35,342 项静止/循环闭合检查通过。45,804 个支撑脚底样本，额外超出旧地面轮廓最多 0.199 世界单位。
- 覆盖所有 40 朝向的原生 Canvas CPU 基准：40 只叠放动物平均约 25.8 毫秒，每只约 0.65 毫秒；40 份编译缓存命中，运行时布尔切分次数为零。这不是 GPU 帧率测试。
- 最终 31 处偏置后的 1,320 组网格、1.85 百万有色三角检查和 1,080 次原生绘制通过；偏置前的完整 11,520 次原生姿态绘制也通过。

透视与运动边界
这是 2.5D 美术动画，纵深步幅按透视压缩；运动循环由距离驱动，但并不宣称所有朝向的脚在世界坐标里严格锁地。保留了原画的朝向、爪子体积和旧地面轮廓，没有为了这种近似扩大碰撞箱。

再现
请以这里的最终 animal_atlas.json 与 source-legs-*.json 为准。早期 .6.1/art-revision 中的骨骼或硬遮罩试验不是发布实现。重新编译时使用已安装 Godot，项目路径设为 output/adventure game 0.1.6.2，再运行 tests/0.1.6.2/gait-uv/compile_skin_topology.gd。
