# Jason 个人网站 · 0.1.0

中英双语个人主页，包含个人介绍、作品集、GitHub 联系入口，以及 Forest Wanderer 的独立游戏空间。

## 正式网站

[打开 Jason 的个人网站](https://forest-wanderer-three-nights-20261017.jasonlifengtong08-05.chatgpt.site/)。目前已公开上线，首页提供中英文切换，Forest Wanderer 游戏文件会在访客点击开始后再下载。

## 本地打开

双击「启动个人网站.command」。它使用 Python 标准库启动仅本机可访问的预览，并自动打开浏览器。关闭预览窗口或按 Control+C 可以停止。也可以从本目录运行 `python3 preview.py`。

## 内容修改

`dist/assets/content.js` 集中保存称呼、双语文案、主题和作品目录。

`site.contacts` 中的 wechat、douyin、phone、gmail 目前为 null，页面不显示空白联系入口。Jason 提供资料后再填写：微信填写账号文本或 HTTPS 分享链接，抖音填写完整 HTTPS 主页链接，电话填写号码，Gmail 填写邮箱地址。已有链接可直接跳转；电话会唤起拨号，邮箱会打开邮件编辑，单独的微信号可一键复制。微信账号无法凭空转换成加好友链接；如果希望微信也直接跳转，请提供微信分享链接或二维码。

## 新增游戏时

**先提醒 Jason 确定新游戏独有的背景、配色、氛围，以及进入游戏空间的过渡效果。** 这是长期项目规则，见 AGENTS.md。

首页保持统一的个人身份。每款游戏通过自己的 `/games/<slug>/` 页面呈现独立世界。主题和作品卡片来自内容配置；新游戏使用自己的页面和资源目录。不要默认复制森林主题到下一款游戏。

## 游戏来源与素材

运行资源来自已完成的 0.1.6.4 网页版，原始 Godot 运行代码、WASM/PCK 分片和高清美术保持不变。仅替换网站外壳与加载入口。首次游戏数据约 113 MB，首页和游戏介绍页不会预先下载。玩家按开始后显示下载进度；下载失败可重新加载并重试。

游戏界面为英文；没有存档，刷新或返回作品集将结束本局。菜单、失焦、隐藏和手机竖屏暂停机制继续保留。物理手机测试范围以验收记录为准。

游戏封面为已批准的 Rowan 森林绿底。作品区使用真实浏览器游戏截图。首页森林插画是为个人网站生成的氛围图，不是游戏截图；原始图与完整提示词归档在项目根 `素材整理/个人网站/0.1.0/`。
