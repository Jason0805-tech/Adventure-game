# v0.1.7 — The Old Beacon（信标主线）

路线图 Phase 1 的第一步：让玩家有明确的目标，而且必须主动去探索。基于 0.1.6.5，旧版本没有改动。

## 新的胜利条件

- 不再是"活过三晚就赢"。昼夜一直循环，不限天数。只有修好并点亮北边大门旁的古老信标，才算逃出森林。
- 第 3 晚以后，野兽难度保持在第 3 晚的水平，不会继续上涨。

## 主线流程

| 步骤 | 地点 | 做法 |
| --- | --- | --- |
| 透镜 Beacon lens | Stillwater 湖南岸的闪光水花 | 用鱼竿在水花旁钓 3 次（在别处钓只会钓到鱼） |
| 齿轮 Bronze gear | 东南矿区的符文岩 | 用镐子敲 6 下，岩石裂开，得到齿轮和 2 块石头 |
| 余烬核心 Ember core | 湖西边森林的石头祭坛 | 按 E 拿走；这里是夜晚狼群的活动区 |
| 修复 | 北门旁的信标 | 3 个零件 + 4 原木 + 2 铁矿 |
| 点火 | 同上，只能在傍晚或夜里 | 3 原木；守在 210 单位的虚线圈内 60 秒 |

- 点火期间，信标会发出逐渐变强的光：照亮周围，也能保护理智。
- 点火期间，火光会吸引附近的狼和熊来查看（测试里狼有 70% 的目标会选在信标附近），这就是最后的挑战。
- 离开虚线圈时进度暂停；天亮前没守完，火就熄灭，原木白烧，下一个晚上再试。
- 左上角新增 GOAL 一栏，随时显示下一步；HUD 显示"Beacon parts x / 3"。手机版也有同样的目标栏。
- Rowan 的对话改为介绍信标任务；Ash 的最后一句改为提示点亮信标；大门会提示需要先点亮信标。

## 美术

- 使用你生成的 `素材整理/信标/0.1.7/信标高清图.png`。程序按像素把它切成 10 张图：信标 3 种状态、符文岩 2 种、祭坛 2 种、零件图标 3 个。切图只做裁剪，没有缩放或重新采样。
- 切好的成品在 `素材整理/信标/0.1.7/production/`，游戏里在 `assets/`。
- 碰撞只拦住每个物件贴地的底座，高处的部分不挡路，和项目原有规则一致。同一个物件的几种状态共用同一块脚底范围，换状态时不会把人卡住。走到物件背后时，高处会变半透明，和树、木屋的处理方式一样。
- 原有的 `collision_profiles.json` 没有修改；新物件的数据单独放在 `assets/beacon_models.json`。

## 网页加载修复（itch.io 卡在 35%）

- 问题：alpha.5 在 itch.io 上加载到 35% 就停住。原因是 itch.io 的服务器传某一块游戏数据（`game.pck.00.bin`）时太慢，最后直接断开了连接（浏览器报 `ERR_CONNECTION_CLOSED`），而旧加载器一块失败就整体放弃，也不会重试。35% 正好是游戏引擎文件下完、准备下游戏数据的那个点。
- 修复（`web-share/loader.js`）：同时下载 3 块；进度条随下载字节实时更新；某一块超过 25 秒没有任何新数据就断开重试，每块最多重试 5 次，期间显示 "Connection slow, retrying…"；数据直接写进最终位置，内存里只保留一份。
- 测试：用一个故意捣乱的本地服务器（第一次传 `pck.00` 时中途断开，第一次传 `pck.03` 时卡住 45 秒），新加载器自动重试后成功进入游戏（GAME_READY v0.1.7）。真正部署到 itch.io 之后的效果，要等你上传后才能验证。

## 手机版检查（上传 itch.io 前）

- 模拟 iPhone SE 横屏（667×375，带触屏）：摇杆能移动角色，Bag 等按钮点了有反应，Rowan 的新对话能完整显示；竖屏时会提示把手机横过来。
- 修复：手机屏幕较窄时，左侧的目标文字会被截断，现在放不下时自动换成两行。
- 仍然没有在真实的 iPhone / 安卓手机上测试过。

## 地图

- 为了给 3 个任务地点腾出空间，固定种子的树少了 4 棵（57 → 53）。随机刷出的资源和矿脉会避开任务地点。

## 修改文件

新增：`beacon_quest.gd`、`assets/beacon_models.json`、10 张信标相关 PNG 及其导入设置。

修改：`main.gd`（接入任务、目标栏、胜利条件、对话）、`item_data.gd`（3 个零件）、`mobile_ui.gd`（手机目标栏和文字）、`world_lighting.gd` 和 `sanity_system.gd`（信标的光）、`wildlife.gd`（野兽被火光吸引）、`project.godot`、`start_web.py`（版本号）。

## 验证

- 新的信标测试共 479 项，用 3 个不同的资源种子各跑一次，全部通过。测试内容：
  - 3 个地点的碰撞不和任何其他物体重叠，都在地图内，并且都能从营地走到。
  - 底座会挡路，高处不挡路。
  - 整条任务流程都调用游戏里真实的函数：真的挥镐、真的抛竿、真的修理和点火，守满 60 秒后获胜。
  - 白天点不着火；离开圈子时进度暂停；天亮会熄火。
  - 连续活过 5 晚游戏也不会自动结束。
- 旧测试全部通过：对话关闭 9 项、生存 46 项、捕食者 72 项、边界 24 项、实际地图动物 45737 项。
- 浏览器里实际看过（用只放在 tests 里的传送测试版）：信标 3 种状态、夜里点火时的光和守护圈、站在信标背后的半透明效果、符文岩、祭坛、湖面闪光、背包里的零件图标、手机横屏 844×390 的界面。另外，正式网页包能启动到 GAME_READY v0.1.7。
- 没测到的：没有人工从头到尾完整玩一遍；实体 iPhone / Safari 也没有测试。难度平衡（守 60 秒到底难不难）需要你实际玩后反馈。

# v0.1.6-alpha.5

基于 0.1.6.4 的修复版。玩法、数值、美术、碰撞都没有改。

## 修复

- **对话关不掉**（问题报告/不能退出对话.png）：站在 Ash 或 Rowan 旁边按 E 关闭对话时，同一次按键还没松开，下一帧就被当成"再次交谈"，对话又被打开，看起来像卡住。现在对话、背包、制作菜单关闭后，要先松开 E / 空格 / 鼠标，游戏才会接受下一次交互。
- 用空格关闭对话时，不会再顺手挥一下手里的工具。
- F3 碰撞调试显示只在调试版里有效，正式导出版自动关闭。以前要为 itch.io 单独删掉这段代码，现在不用了。

## 修改文件

`main.gd`（输入锁定 + F3 限调试版 + 版本号）、`mobile_ui.gd`、`project.godot`、`start_web.py`（版本号）。重新导出了 `web-share/`。

## 验证

- 新增 `其他/tests/0.1.6.5/test_dialog_close.gd`，共 9 项检查，用真实的 Godot 输入事件模拟"按住 E / 空格"。0.1.6.4 失败 5 项（复现了 bug），0.1.6.5 全部通过。
- 0.1.6.4 原有的回归测试在新版上全部通过：生存 46 项、捕食者 72 项、边界 24 项、实际地图动物 45737 项。
- 在浏览器里实际运行：正式网页包启动到 GAME_READY v0.1.6-alpha.5，没有报错；用只放在 tests 里的测试版（开局站在 Ash 旁边、NPC 不走动）实测：按 E 打开、按 E 关闭后对话没有再弹出，点 Continue 按钮也能关闭，关闭后时钟恢复走动。
- 浏览器测试工具只能"轻点"按键，不能真正按住，所以"按住"的情况只在 Godot 无界面测试里验证过。实体 iPhone / Safari 仍然没有测试。

# v0.1.6-alpha.4

基于 0.1.6.3 的独立工程，用作 v0.1.6-alpha.4 公开预发布。旧版和历史版本不修改。

## 实现内容

- 理智 0–100，初始 100；NORMAL / UNSTABLE / CRITICAL 三档。增加纸质风格状态栏，桌面和手机均可见。
- 黑暗、严重饥饿、危险遭遇影响理智；灯光、真正安全的营地休息、实际消耗的食物帮助恢复。
- 轻微边缘压暗和稀疏环境幻象不改变碰撞。真正暗影最多一只，复用原狼美术、步态、地面轮廓和战斗；只在夜间低理智黑暗中生成，选择 360–520 单位外的合法连通位置，保留 4 秒出生缓冲。
- 狼短时间快于玩家，之后疲劳；灯光降低追击压力，遮挡可切断追踪。熊增加锁定方向的短冲锋、明确 CHARGE 预警和冷却。
- 移除营地周围的动物隐形围墙。灯光仍有用，但不是免疫区。第二、三晚一只北部栖息地的狼会尝试调查营地灯光，不读取隐藏玩家的位置，不增加同时存在的敌人上限。
- 铁斧和升级剑动作更快。保留原 11 个配方，工作台追加魔法石配方；Ash 首次交谈给鱼×2、药×1、魔法石×1，不能重复领取。移除旧的击杀“Experience”提示和隐藏累加值，进展依靠装备与资源。
- 原画、全部 45 张游戏 PNG、动物网格数据、地面碰撞、深度排序、角色握持、NPC 步态、昼夜时长和三夜目标保留。营地昼光光环修复及灯光网格生命周期修复保留。

## 平衡数值

| 机制 | 数值 |
| --- | --- |
| 饥饿 | 8 点/分钟；低于 25 时移速逐渐降至最低 92%，行动最多慢 12% |
| 饥饿归零 | 每秒损失 0.8 生命；低于 10 额外每秒损失 0.10 理智 |
| 夜间无保护光 | 每秒损失 0.35 理智；白天无被动黑暗消耗 |
| 安全营地休息 | 静止且不行动 3 秒后，每秒恢复 0.25 理智；饥饿照常消耗 |
| 危险遭遇 | 一次损失 5 理智，整个兽群共用 24 秒冷却；持续在视野里不重复收费 |
| 食物 | 浆果最多 +22 饱食 / +2 理智；鱼最多 +25 / +4；理智按实际补回的饱食比例计算，不能靠补 1 点饥饿刷整份奖励 |
| 暗影 | 理智 <30 才生成；最多 1，只生成在合法且可通行的位置；冷却 50 秒，失败重试间隔 3 秒；42 生命、103 追击速度；到有效灯光、白天或理智 >35 时消散，无额外资源奖励 |
| 狼追击 | 第 1/2/3 晚为 116/118/120；连续追击 6/8/10 秒后休息 4.5 秒；灯光下减速，保留咬击前预警 |
| 熊 | 普通追击 74/77/80；冲锋 150/158/166，先预警 1.05 秒，再固定方向冲锋约 0.62 秒；冷却 11/9/7.5 秒 |
| 同时存在数量 | 普通狼 2/3/3，熊最多 1；不会靠无限增加同时存在的动物制造难度 |
| 工具升级 | 铁斧挥动 0.58 秒且每击 2 点树木伤害；升级剑挥动 0.60 秒、48 伤害；普通斧/剑 0.80 秒 |
| 防御制作 | 工作台：铁矿×1 + 石头×2 + 纤维×1 → 魔法石×1；每颗只抵挡一次实际命中 |
| 时间 | 白天180秒、傍晚6秒、夜晚90秒，3晚获胜；所有菜单/失焦/竖屏暂停全部时钟、AI与动作 |
