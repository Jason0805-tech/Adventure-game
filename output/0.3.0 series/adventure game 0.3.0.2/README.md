# Forest Wanderer — v0.3.0-alpha.2

v0.3.0 地图扩展：地图从一片森林扩大成三个区域——原来的**低语森林**、东边的**河谷**（河、桥、浅滩、芦苇、鳟鱼）和南边的**废墟**（闹鬼、古石料、碎石堆）。三个信标零件分在三个区域。详见 CHANGELOG.md。alpha.1 换上了新区域的正式美术，alpha.2 补上土路、沉井和倒塌石门。

新的主线：修复森林里的古老信标，点亮它，逃离森林。基于 0.1.6.5，英文游戏界面，保留原来的高清油画美术、角色动画和全部生存系统。

## 打开游戏

- 直接玩网页版：双击 **启动网页版.command**。保持弹出的窗口打开，浏览器会打开这一版游戏。停止时在该窗口按 Control+C。
- 修改工程：用已安装的 Godot 4.7.2 导入本文件夹里的 **project.godot**，按 F6 或 F5 运行。
- 请保留整个版本文件夹。`web-share/index.html` 需要通过启动器打开，不能把这个小 HTML 文件单独发送给朋友。

启动器会在当前电脑开启本地网页服务，不会把游戏托管到公网。此版本可通过 GitHub 预发布包下载；实体 iPhone / Safari 和微信内置浏览器尚未测试。手机按钮和布局保留在网页版中；在地址末尾加 `?touch=1` 可以在电脑上预览手机布局。

## 这一版怎么玩

白天 120 秒，傍晚 6 秒，夜晚 90 秒，昼夜一直循环，不限天数。刷新或关闭后重新开始，没有存档。

**主线目标：点亮古老信标。**

1. 找齐 3 个零件：
   - 透镜：东边河谷里，旧渡口（Old Ferry）旁的河面有一处闪光的水花，拿鱼竿在那里钓 3 次。过河要走旧桥或浅滩。
   - 齿轮：南边废墟的中央广场有一块刻着螺旋符文的岩石，用镐子敲 6 下。废墟会让你掉理智，带上火把或符文护符。
   - 余烬核心：湖西边的森林里有一座石头祭坛，按 E 拿走。
2. 带着 3 个零件、4 根原木和 2 块古石料（废墟碎石堆用镐挖），到北边小路旁的信标处按 E 修复。
3. 天黑后带 3 根原木再来按 E 点火，然后守在信标附近（地上的虚线圈内）60 秒。火光会吸引狼和熊。离开圈子时进度暂停；天亮前没守完，火会熄灭，第二晚再试。
4. 守满 60 秒，信标点亮，照亮回家的路，通关。守夜时会有几波狼（第 3 晚以后还有熊）从树林里冲向篝火，这就是最后的挑战。

**每晚不一样**：第 1 晚平静；从第 2 晚开始，每晚会有一个夜间事件（狼群嚎叫、浓雾、暴躁的熊、血月），黄昏时会预告，夜里左上角会显示。

左上角的 GOAL 一栏会一直告诉你下一步该做什么。按 J 打开任务日志：主线进度、已发现的地标、补给箱和探索进度一目了然。地图上有 8 个地标（第一次走到会给奖励，其中 3 个会教你铁器配方）和 4 个藏起来的补给箱。

- WASD / 方向键移动，按住 Shift 冲刺（约 4 秒耐力），M 打开地图，J 打开任务日志；E 采集、交谈、使用工作台；Space / 点击使用当前物品。
- B 背包；C 野外制作；1–6 选择快捷栏；H 用药；T 切换副手火把。手机布局保留 Move、Gather、Use、Bag、Craft、Heal、Torch、Pause。
- 夜间无灯时每秒减少 0.35 理智。火把和营地灯可以保护理智。站在营地灯下、停止移动和行动、附近没有危险动物，3 秒后开始恢复理智。
- 营地灯会拖慢捕食者并让它们犹豫，但不能保证你不受攻击。背包、制作、对话、暂停、失焦或手机竖屏会暂停整个世界。
- 夜里狼和熊会顺着你留下的气味找过来；砍树、挖矿、打斗和冲刺的声音、以及火把的光都会引来它们。狼能短时间追上你，但会疲劳。利用灯光、障碍和攻击预警脱身。熊出现 CHARGE 预警后向侧面移动。
- 理智低于 70 会出现轻微视觉干扰；低于 30 可能出现一只真正可战斗的暗影。找灯光、恢复到 35 以上或击败它都能消除威胁。
- 饥饿每分钟消耗 8 点。浆果和鱼是食物；鱼也恢复少量理智。铁斧采集更快，升级剑挥动更快，工作台新增魔法石配方。第一次拜访 Ash 可获得一次补给。

## 文件

`main.gd` 是入口；信标主线在 `beacon_quest.gd`，信标美术的碰撞和尺寸在 `assets/beacon_models.json`；理智规则在 `sanity_system.gd`，平衡数值在 `survival_balance.gd`，捕食者战术在 `predator_behavior.gd`。`assets/` 是原始高清素材。`tools/` 内保留官方单线程 Web 导出模板，所以再次导出不依赖旧版本文件夹。

详细修改、数值和验证范围见 **CHANGELOG.md**。所有测试脚本、日志和截图保存在项目根目录的 `其他/tests/0.1.7/`；更早的玩法测试在 `其他/tests/0.1.6.4/`。
